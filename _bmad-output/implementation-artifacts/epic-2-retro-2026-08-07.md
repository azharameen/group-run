## Successes

### 1. Error Recovery Implementation (ST-2.7)
ST-2.7 delivered comprehensive error handling: 120s agent timeout, exponential backoff retry (2 retries, 1s/2s delays), structured error responses with code/message/retryable, and MCP HTTP timeout configuration. This directly addressed a key Epic 1 action item. 28 new tests added with full coverage of timeout, retry, and graceful degradation paths.

### 2. Thread Checkpoint Restoration (ST-2.2)
Thread switching with full message history restoration works. The async SQLite conversion eliminated sync blocking. The stale-fetch guard pattern (fetchCounterRef) prevents message bleeding during rapid thread switches.

### 3. Test Coverage Expansion (ST-2.3, ST-2.6, ST-2.7)
- ST-2.3: 29 backend tests (checkpoint restoration, thread isolation, error handling, service layer)
- ST-2.6: 26 frontend tests (13 useThreadManager hook tests, 13 NavThreads component tests)
- ST-2.7: 28 error recovery tests (timeout, retry, structured errors, MCP timeout)

### 4. API Route Cleanup (ST-2.1)
Reduced threads.py from 227 to 138 lines (39% reduction). Moved shared schemas to a common module. All CRUD routes verified with 14 tests including real LangGraph checkpoint integration.

### 5. Thread Management Hook (ST-2.4)

## Key Insights

1. **ST-2.7 Proves Targeted Debt Reduction Works** - The ainvoke() timeout was an Epic 1 action item. ST-2.7 resolved it with 28 tests. When debt items are tied to a specific story, they get done.

2. **SQLite Is Our Scaling Bottleneck** - Sync blocking (ST-2.2), AsyncSqliteSaver.setup() overhead (ST-2.2 deferred), connection never closed (ST-2.1 deferred), deprecation warnings (ST-2.3 deferred). SQLite needs a dedicated hardening story in Epic 7.

3. **Test Coverage Is Strong** - 102+ tests across backend and frontend. ST-2.3 isolated threads correctly. ST-2.6 caught rename/delete flow gaps during review. Quality is good when we test.

4. **Retro Accountability Is Broken** - 3 epics completed, retro action items consistently not followed. Epic 0: 2/5 done. Epic 1: 1/6 done. We need to either reduce action items or make them story-scoped.

5. **Deferred-Work.md Needs Active Triage** - The file exists but is never reviewed. Deferred items should be reviewed at the start of each retro, not just appended to.

## Significant Discoveries

1. **idea_id Is Unused in Stream Endpoint** - ST-2.1 discovered idea_id is accepted in stream endpoint but never passed to ainvoke(). Pre-existing pattern, but means Epic 3 (Ideas Management) will need this wired up.

2. **LangGraph .wrapped Attribute Handling** - ST-2.1 discovered messages are stored with .wrapped attribute, not raw list. This is a LangGraph 0.6.x detail that was undocumented. Future checkpoint consumers need to handle this.

3. **Thread Isolation Verified** - ST-2.3 confirmed thread A messages never leak to thread B, deleted thread messages become inaccessible, and concurrent streams do not mix. Thread safety is solid.
