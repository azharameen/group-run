- (decision) AD-1: Standardize on SQLAlchemy 2.0 AsyncEngine + psycopg/asyncpg + langgraph-checkpoint-postgres for all database interactions and state persistence.
- (decision) AD-2: Dual-mode Postgres configuration (Local direct vs Supabase Transaction Pooler PgBouncer port 6543 / Direct port 5432) controlled via Pydantic settings without code changes.
- (decision) AD-3: Implement Repository Pattern with Abstract Base Interfaces (IOrganizationRepository, IWorkItemRepository, etc.) to decouple business logic from underlying DB driver.
- (decision) AD-4: LangGraph state checkpointer migrated from SqliteSaver to AsyncPostgresSaver backed by Postgres connection pool with startup lifespan initialization.
- (decision) AD-5: DDL versioning and schema migrations managed via Alembic instead of raw per-repository CREATE TABLE calls.
- (decision) AD-6: Test suite isolation using PostgreSQL test database/schema fixtures and savepoint rollback; complete removal of in-memory SQLite test fixtures.
- (decision) AD-7: Zero SQLite policy — complete removal of sqlite dependencies, sqlite storage files, sqlite3 imports, and sqlite documentation references across the codebase.
