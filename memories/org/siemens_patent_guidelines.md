# Siemens Patent Guidelines & Governance

## Disclosure Quality Requirements
- Title must be descriptive, concise, and non-promotional.
- Technical problem must present existing state of the art limitations.
- Detailed solution must include at least one functional architecture block diagram or workflow sequence.

## IP Protection Levels
- High Priority: Core platform innovations subject to global filing (EP, US, CN, JP).
- Standard Priority: Regional implementation details.
- Trade Secret Candidate: Pure software algorithms without physical/system integration evidence.
