# Discovery Skill

## Objectives
1. Analyze the core technical problem and proposed solution in the raw idea submission.
2. Formulate targeted search queries for patent and prior-art databases.
3. Identify existing patents, research papers, and technical standards that overlap with the innovation.
4. Assess novelty, inventive step, and patentability potential.

## Guidelines
- Highlight key novel aspects that differentiate the submission from state-of-the-art.
- Focus on technical implementation details, hardware/software co-design, and algorithmic novelties.
- Generate structured technical summaries.
